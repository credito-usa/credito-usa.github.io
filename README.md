# CréditoUSA

Guía educativa gratuita en español para hispanos en EE.UU. sobre cómo hacer crédito: puntaje de crédito, tarjetas aseguradas (secured), tarjetas con ITIN y finanzas personales.

- Idioma: español (EE.UU.)
- Audiencia: hispanos en EE.UU., recién llegados o sin historial crediticio, con o sin SSN, con ITIN.
- Estado: contenido 100% educativo, sin enlaces de afiliado (se añadirán cuando existan programas).

## Páginas

| URL | Contenido |
|---|---|
| `/` | Hub principal: cómo hacer crédito en USA paso a paso + puntaje + asegurada + ITIN + fácil aprobación |
| `/facil-aprobacion/` | Tarjetas de crédito de fácil aprobación: precalificación, tipos, cómo solicitar |
| `/tarjetas-con-itin/` | Tarjetas de crédito con ITIN por banco: Chase, Discover, Citi, Capital One, Amex, Wells Fargo + fintechs |
| `/tarjeta-asegurada/` | Tarjeta asegurada (secured): guía completa, comparativa y upgrade |
| `/puntaje-de-credito/` | Puntaje de crédito: factores FICO, tabla 300-850, hábitos y mitos |
| `/mejores-tarjetas-hispanos/` | Mejores tarjetas para hispanos: criterios, etapas y errores |
| `/acerca-de.html` | Misión, política editorial, afiliados y autor |
